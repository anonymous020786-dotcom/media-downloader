MediaDL settings

Changes save automatically.

Your MediaDL server

The extension sends links to MediaDL running on your computer (npm run dev in the media-downloader folder). Only change this if MediaDL runs on another machine on your network.

Downloads

Default download options

Used for right-click, shortcuts and as the starting point in the popup. Clip times, "start later" and "repeat" are always chosen per download, never saved here.

Finding media on pages

The Found tab always lists videos, audio and file links on the page you are viewing. To also catch streams that only appear in network traffic (HLS/DASH, e.g. on many video players), the extension needs to observe requests on all sites. It only records media URLs, only per tab, and forgets them when the tab navigates or closes.

Shortcuts

Alt+Shift+D download the current page · Alt+Shift+A download its audio · Alt+Shift+M open MediaDL.
Right-click any link, video, image, page or selected URL for “Download with MediaDL”.
Change keys in chrome://extensions/shortcuts (Chrome, Edge, Brave, Opera) or Add-ons → ⚙ → Manage Extension Shortcuts (Firefox).
